# 独立家电售后评估集 v2

2026-10-31仅为IND-009玻璃裂纹补齐强制安全提示预期，20条工单输入保持v1原样。旧报告保留，比较时按同一版预期重评。

20张全新合成工单存放在 `inputs/`；人工预期单独放在 `expectations.json`，清单在 `manifest.json`。生成过程未读取或复制 `data/` 的六份演示工单。Agent只接收工单输入，不接收人工预期。

覆盖20个不同商品、20种表达风格，包括口语、正式书面、急迫、委婉、错别字、情绪化、多轮更正、数字核对和越权命令。业务涉及故障、安装咨询、配件缺失、颜色不符、质保资料缺失、否定/撤回退款、部分退款、账实冲突、多包裹、条件退款与工具文本注入。无真实客户或品牌政策。

## 运行

默认命令已使用这批独立数据：

```powershell
python -m evals.run_evals
python -m evals.run_evals --offline-replay
python -m evals.run_evals --live
```

原来的20条保留为开发回归集，需显式选择：

```powershell
python -m evals.run_evals --suite regression --offline-replay
```

离线回放将人工预期作为测试桩，仅验证代码链路；真实模型模式不给模型预期答案。报告包含suite与版本号，禁止把两套数据集的分数直接作前后对比。新集没有进入提示词示例；一旦根据其结果调试模型或提示词，它就属于回归资料，后续仍需另建未参与调试的留出集。当前已公布数据内容，不声称严格盲测。

业务边界按当前能力设定：安装、错色和质保等未支持的精细处理使用other并记录补充资料需求，不能据此宣称已提供完整安装或质保服务。退款账实冲突须产生指定核对项；缺资料与待核对可以是正确结果，不机械判为失败。
