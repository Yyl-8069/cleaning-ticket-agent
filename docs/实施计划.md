# 家电售后工单 Agent v1.0：架构与版本记录

本文件说明公开v1.0的实现，当前能力以代码与README为准。

## 需求与流程

面向运营客服，将工单、订单、商品、物流、历史记录和规则的查阅过程组织为可追踪分析，输出依据、建议和回复草稿。

上传JSON → 校验大小/类型/时间/金额/关联编号 → SQLite保存案例并创建运行 → FastAPI后台任务 → LangChain单Agent按需调用六类只读工具 → 输出校验 → 保存结果和事件。

## 模块边界

- app负责HTTP、页面、数据库生命周期与JSONL日志。
- context负责输入校验，不让无效编号关联进入流程。
- workflows负责queued/running/终态与失败处理。
- agents负责模型消息、工具调用预算和结构化结果校验。
- tools分别查询当前案例的工单、订单、商品、物流、历史与规则。
- prompts按角色、任务、约束、示例和schema拆分，版本随Git保存。
- tests检查代码行为；evals检查固定输入和模型输出，成绩分别解释。
